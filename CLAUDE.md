# REGOLE
- rispetta output-styles e "outputStyle": "Minimal"
- leggi [INDEX](INDEX.md)
- per le ricerche web usa fonti ufficiali; se non esistono (es. mercato, assunzioni junior in Italia) usa altre fonti e dichiaralo
- se non trovi una informazione, non inventare ma piuttosto cerca sul web e se non trovi l'info nemmeno cosi (dopo aver provato anche fonti non ufficiali) avverti Andrea
- la tua fonte di memoria è `notes/`
- non puoi scrivere in memory
- non prendere `notes/` come unica fonte di verità, ogni 3 giorni metti in dubbio te stesso `notes/auto-dubbio`
- tendenzialmente anche i file in `notes/` vanno scritti sintetici e minimal
- quando sviluppi un blocco o un singolo punto scrivi un piano di intervento minimale in forma di lista, in forma brevissima (vince l'output style)
- se un'istruzione ha più punti (passi, comandi, piani), presentali un punto alla volta: dai il primo, aspetta Andrea, poi il successivo
- quando consigli comandi bash spiegali a fine messaggio, in forma di lista ogni sua singola parte
