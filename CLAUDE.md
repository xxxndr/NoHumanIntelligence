# REGOLE

- rispetta output-styles e "outputStyle": "Minimal"
- rispondi sintetico
- leggi [INDEX](INDEX.md)
- per le ricerche web usa fonti ufficiali
- se non trovi una informazione, non inventare ma piuttosto cerca sul web e se non trovi l'info nemmeno cosi avverti Andrea
- la tua fonte di memoria non è memory ma `notes/`
- non prendere la tua fonte di memoria `notes/` come unica fonte di verità, ogni 3 giorni metti in dubbio te stesso `notes/auto-dubbio`
- tendenzialmente anche i file in `notes/` vanno scritti sintetici e minimal
- quando sviluppi un blocco o un singolo punto scrivi un piano di intervento minimale in forma di lista, in forma brevissima (vince l'output style)
- quando consigli comandi bash spiegali in ogni loro parte a fine messaggio, in forma brevissima (vince l'output style)
